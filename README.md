# North Star Bakery — Touchstone 3

This is a four-page mobile-first website for the North Star Bakery student project.

## Pages
- `index.html` — homepage
- `products.html` — bakery menu
- `about.html` — bakery story and supplied welcome audio
- `contact.html` — accessible sample preorder request form

## Features
- External CSS; four-color palette (#FFF8F0, #6B3E26, #D88C5A, #2F2A26)
- Georgia headings and Arial body text
- Flexbox layouts with a breakpoint at 720px
- Original client-supplied photos, optimized as JPGs; responsive `<picture>` element and captioned `<figure>`
- Original client-supplied audio
- Four linked pages, skip links, accessible controls and validation

The preorder form is a **classroom demonstration only**, not a real submission service. No customer data is sent anywhere. The large client video was not included to keep this student website small and easy to publish; the supplied audio satisfies the audio/video requirement.

## Preview
Open `index.html` in a browser, or publish the full folder with GitHub Pages.

## Publish to GitHub Pages
1. Create a free GitHub account at github.com.
2. Create a **public** repository named `north-star-bakery` and choose **Add a README** only if you do not already have one.
3. Upload the website's **individual files and assets folder** to the repository root. Don't upload the ZIP alone.
4. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Once GitHub publishes the website, copy the URL displayed in Pages settings into the assignment document. Your repository URL will also be visible in the browser address bar.

Use no made-up live URL in the submission: wait until the actual GitHub Pages URL has loaded successfully.
